# E-Commerce Lyrata Joias

## Sobre
O site tem como objetivo transmitir a identidade da marca, destacando a beleza e a delicadeza das peças, além de proporcionar uma apresentação clean e funcional para quem deseja conhecer e comprar acessórios femininos com estilo. A estrutura foi pensada para ser responsiva, acessível e fácil de manter, com foco em uma boa experiência de compra e em uma apresentação visual atrativa.

## Nome
Lyrata é um nome derivado de Lyra, uma constelação pequena mais muito brilhante. Dessa forma, as joias apresentadas na loja possuem os nomes das estrelas presentes na constelação e e de outros astros do céu.
